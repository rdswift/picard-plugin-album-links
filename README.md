# Album Links

## Overview

This plugin provides quick links to an album's related web pages from the "Plugin Tools" menu.

---

## What it Does

This plugin reads the album metadata provided to Picard for the selected album and creates a list of related website links which can be displayed from the "Plugin Tools" menu.
